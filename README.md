# Stock predicting project using ML algorithms

## Getting Started

### Prerequisites

Make sure you have the following software installed:

- Python (version 3.12.3)


### Installation

To ensure all the needed Python libraries are installed, follow these steps:

1. Clone the repository:
    ```sh
    git clone https://github.com/pasztics1/stock_project
    cd stock_project
    ```

2. Run the `build.bat` file to install the required libraries and the necessary wheel file:
    ```sh
    build.bat
    ```
